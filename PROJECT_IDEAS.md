# Coding Project Ideas for Parent + 10-Year-Old

These ideas are beginner-friendly and can be built in small steps with Codex.

## Current Game Library
- `family_quiz/quiz.py` — Family Quiz Game
- `family_puzzle/puzzle_game.py` — Family Puzzle Game

## 1) Family Quiz Game (Terminal or Web)
- Build a multiple-choice quiz on topics your son likes (animals, space, Minecraft, soccer).
- Concepts: variables, conditionals, loops, lists, scoring.
- Extensions: timed rounds, random questions, high score file.

## 2) Chore + Reward Tracker
- Simple app to add chores, mark complete, and earn points.
- Concepts: CRUD (create/read/update/delete), data persistence (JSON), functions.
- Extensions: weekly reset, streaks, badge unlocks.

## 3) "Guess the Number" With Difficulty Levels
- Start with classic guessing game.
- Concepts: input/output, while loops, comparisons.
- Extensions: easy/medium/hard, hints, attempt counter, leaderboard.

## 4) Story Generator
- User picks characters/places, app generates a silly story.
- Concepts: strings, templates, arrays, randomization.
- Extensions: save stories to file, emoji mode, voice narration.

## 5) Drawing App (Canvas)
- Basic web page where user can draw with mouse.
- Concepts: events, coordinates, UI controls, state.
- Extensions: brush sizes, color picker, clear/save image.

## 6) Mini Math Trainer
- Practice addition/multiplication with increasing difficulty.
- Concepts: random numbers, scoring, functions, game loop.
- Extensions: 60-second challenge, chart progress over time.

## 7) Simple 2D Game (Catch the Falling Stars)
- Move a basket to catch objects.
- Concepts: animation loop, collision detection, keyboard input.
- Extensions: levels, power-ups, lives.

## 8) Pet Mood Simulator
- Virtual pet that gets hungry/happy/tired over time.
- Concepts: object state, timers, conditionals.
- Extensions: feed/play/sleep buttons, save pet state.

## 9) Weather + Outfit Helper
- Pull weather data and suggest clothing.
- Concepts: API requests, JSON parsing, branching logic.
- Extensions: favorite cities, weather icons, alerts.

## 10) "Code Detective" Puzzle Game
- Player solves logic puzzles and simple coding riddles.
- Concepts: problem decomposition, functions, validation.
- Extensions: hints, levels, puzzle editor.

## Recommended First Project
Start with **Family Quiz Game**. It is quick to build, easy to personalize, and naturally teaches the core building blocks of programming.

## Suggested Learning Plan (4 Short Sessions)
1. Build the smallest playable version (5 questions, score only).
2. Refactor into functions and add randomization.
3. Save/load high scores from JSON.
4. Add your own UI polish and custom question packs.
